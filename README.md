# قهوة الأصالة — موقع منيو تفاعلي

موقع حقيقي يعمل على سيرفر: الزبون يطلب من جواله، والإدارة تستقبل الطلبات وتدير المنيو من جهازها. كل البيانات مشتركة بينهم لحظياً.

## المحتويات
- `server.js` — السيرفر (Node.js + Express)
- `public/index.html` — واجهة الزبون
- `public/admin.html` — لوحة الإدارة
- `data.json` — قاعدة البيانات (تُنشأ تلقائياً عند أول تشغيل)
- `public/uploads/` — صور الأصناف المرفوعة

## التشغيل على جهازك (محلياً)
1. ثبّت Node.js من https://nodejs.org
2. افتح المجلد في الطرفية ونفّذ:
   ```
   npm install
   npm start
   ```
3. افتح المتصفح:
   - الزبون: http://localhost:3000
   - الإدارة: http://localhost:3000/admin.html

الرمز السري الافتراضي للإدارة: **1234**

## تغيير الرمز السري
الأفضل عبر متغير بيئة عند التشغيل:
```
ADMIN_PIN=رمزك_السري npm start
```
أو على منصات الاستضافة، أضفه في Environment Variables باسم `ADMIN_PIN`.

## النشر المجاني (لكي يفتحه الزبائن من أي مكان)

### الطريقة الأسهل: Render
1. أنشئ حساباً مجانياً على https://render.com
2. ارفع المشروع على GitHub
3. في Render اختر New > Web Service واربطه بمستودع GitHub
4. الإعدادات:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. أضف متغير بيئة `ADMIN_PIN` بالرمز الذي تريده
6. بعد النشر ستحصل على رابط مثل `https://your-cafe.onrender.com`

> ملاحظة: في الخطة المجانية، الملفات المرفوعة و`data.json` قد تُحذف عند إعادة تشغيل الخدمة. للإنتاج الجاد استخدم قرصاً دائماً (Disk) أو قاعدة بيانات خارجية.

### بديل: Railway
نفس الفكرة على https://railway.app — اربط GitHub، يكتشف Node تلقائياً، أضف `ADMIN_PIN`.

## كيف تشارك المنيو مع الزبائن
بعد النشر، حوّل رابط الموقع إلى **QR Code** (من أي موقع مجاني لتوليد QR) واطبعه على الطاولات. الزبون يصوّره فيفتح المنيو ويطلب.
